# 方块与花园 · MC × PVZ

在线资源工作台：https://0everey.github.io/mc-pvz-room/

默认中档资源格，主体自适应取景；配方直接展示材料与产物，定义资源按类型预览，MC／PVZ菜单分别配色。 支持手机横竖屏、触屏缩放与复位；精选交错展示两侧资源，页脚报告实际预览就绪，失败项可单独重试。支持逐项试听、动画预览、路径复制、多级分组及多选原件ZIP。 分类旁可直接下载整类、全部筛选结果或已有选集；分类包带中文使用说明和清单，支持复制完整使用清单、保存JSON及分享公共分类链接。首屏提供真实目录，默认浏览全库；搜索、分类和分享目标按小包优先读取，详情和原件不等完整身份包。当前页面使用动态优先队列：可见资源和详情先于离屏与后台准备，逐项显示已就绪内容；已有选集和私人分组在完整身份校验后恢复，音频点击后读取。网页按需读取资源，运行不调用在线模型；访问者无需安装Python或下载整包。

可下载本库根目录MC-PVZ.html作为独立轻入口，它会打开上方HTTPS网页。
